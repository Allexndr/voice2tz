# Voice2TZ

Локальное macOS-приложение для пакетной расшифровки голосовых сообщений и подготовки документов по итогам разговора. Оно преобразует аудио в текст с помощью Whisper на Apple Silicon, а затем по выбору формирует техническое задание, список задач или краткое резюме.

## Возможности

- Пакетная загрузка файлов OGG, OPUS, M4A, MP3, WAV, AAC, WEBM, FLAC, MP4 и MOV.
- Распознавание русского, казахского и английского языка, а также автоматическое определение языка.
- Выбор моделей Whisper: large-v3-turbo, large-v3, medium и small.
- Подготовка подробного ТЗ, списка задач, краткого резюме или одной стенограммы.
- Выбор локального Ollama, OpenAI, Anthropic или режима без LLM.
- Скачивание результата и полной стенограммы одним Markdown-файлом.

## Требования

- Mac с Apple Silicon и macOS.
- Python 3.11.
- Подключение к интернету для установки пакетов и первой загрузки выбранной модели Whisper.
- Ollama — только если выбран локальный AI-анализ. Для OpenAI и Anthropic нужны API-ключи соответствующих сервисов.

MLX Whisper рассчитан на Apple Silicon. Проект не предназначен для запуска на Windows или Linux без замены слоя распознавания речи.

## Установка и запуск

```bash
git clone <URL-репозитория>
cd voice2tz
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
./launch.sh
```

После запуска приложение откроется в браузере. Перетащите одно или несколько голосовых сообщений в область загрузки, выберите параметры распознавания и нажмите «Расшифровать и составить ТЗ».

Можно запустить Streamlit напрямую:

```bash
source .venv/bin/activate
streamlit run app.py
```

Модели Whisper загружаются по требованию и сохраняются в локальном кэше Hugging Face, а не в папке репозитория.

## AI-провайдеры

### Ollama

По умолчанию приложение обращается к `http://localhost:11434` и использует модель `qwen2.5:latest`. Убедитесь, что Ollama запущен, а выбранная модель установлена. URL и имя модели можно изменить в боковой панели.

### OpenAI и Anthropic

Укажите ключ в поле приложения или задайте переменную окружения `OPENAI_API_KEY` либо `ANTHROPIC_API_KEY`. Не добавляйте ключи в исходники, README или Git.

## Обработка аудио и приватность

Распознавание выполняется локально с помощью MLX Whisper. Для обработки приложение временно записывает загруженный аудиофайл и удаляет его после попытки расшифровки. Вес выбранной модели кэшируется локально.

Если выбран OpenAI или Anthropic, приложению передаётся текст стенограммы для подготовки результата. Сам аудиофайл этим провайдерам код приложения не отправляет. При использовании Ollama стенограмма отправляется на настроенный Ollama URL; по умолчанию это локальный адрес. Перед обработкой конфиденциальных записей проверьте выбранного провайдера и его настройки.

Результат скачивается пользователем в браузере. Приложение не создаёт в репозитории архив голосовых файлов или стенограмм.

## Состав проекта

- `app.py` — интерфейс Streamlit, распознавание и AI-анализ.
- `launch.sh` — запуск приложения из локального виртуального окружения.
- `requirements.txt` — версии Python-зависимостей.
